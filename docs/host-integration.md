# Host integration contract

The manifest registers development availability only. Keep `liveEnabled: false`; a production catalog entry is not a working connection. Repository URLs are internal developer references and should not appear in public product UI.

## Read-only pipeline

1. Authenticate in TakeAgent and derive tenant, authorized project, currency and current UTC date on the server. Check plan entitlement, origin, payload/rate limits and revocation before reading an upload. Never trust these values from a submitted JSON body.
2. Present instructions to select only account-level cost columns, not employee, payroll, banking or payment data. For CSV, call `parseCsv` to inspect bounded headers and require explicit mapping. `previewCsv` rejects unused columns; no quiet whole-workbook upload is supported. Metadata and source control totals must be reviewed separately.
3. Call `previewCsv(text, {mapping, metadata, totals}, trustedContext)` or `preview(normalizedReport, trustedContext)`. Display all warnings, report date, source identity/revision, distinct cost measures, amount unit and reconciliation result. Never render imported text as HTML or instructions. Inputs are transient; library has no persistence, credentials or network requests.
4. If an existing snapshot is present, re-check its server ownership and call `compare`. Display account additions/removals and deltas. A reused revision with changed content is a conflict, not an overwrite. Duplicate fingerprints are no-ops. A revision compare result is not an apply authorization.
5. Optionally call `previewBudgetMapping` with the host's current Movie Magic/imported budget account IDs and explicit one-to-one links. Hierarchy is retained from the host budget. Missing links remain visible; duplicates, unknown IDs and invalid hierarchy fail. Never infer a mapping by description or replace original/revised budget values. Many-to-one allocation requires future explicit allocation support.
6. `costFindings` supplies descriptive source-linked cost questions only. Pass the separate evidence-backed finance plan to TakeAgent's existing finance-review service for financing analysis. The adapter deliberately reports fundingGap/cashTimingGap as null: accounting EFC is not committed funding or a dated cash schedule.

## Storage and apply gate

There is no apply endpoint in this repository. If the host later adds cost-snapshot persistence, it must use explicit user confirmation, project-version concurrency checks, tenant-scoped idempotency keys and separate cost-snapshot storage, without changing finance-plan commitments. Disconnect must revoke credentials and delete retained snapshots according to documented retention. Host authentication, billing, deletion and concurrency integration tests are required before exposing uploads to real customers.

## Supported file contract

CSV is a bounded selected table, not a certified EP export version. UTF-8 text <=2 MB, <=64 columns, <=10,000 data records, <=2,000 characters per cell; the snapshot itself caps detail rows at 10,000. Exact decimal strings, no currency symbols/grouping/formulas. Parenthesized credits, thousands separators and locale decimal commas are rejected with distinct `INVALID_AMOUNT_*` codes; normalize on the host before calling `preview`. Seven distinct mapped columns: account plus six cost measures. No subtotal rows. Control totals come from the source report, not a sum generated by this adapter. No automatic FX conversion. USD/EUR/GBP/CAD/AUD only.

`metadata.reportScope` must explicitly equal `full-project-unfiltered`; the host must verify this declaration from the report settings with the user. Filtered location/account/period subsets cannot be imported as complete projects. Multiline headers are rejected; accepted account/amount values cannot contain line breaks, preserving physical CSV row references.

Native XLSX, merged/hierarchical vendor export layouts, partial-period reports, paid/unpaid AP reconciliation and source hierarchy extraction are not yet supported. Convert a reviewed selected values-only table to CSV while vendor fixtures are pending; this does not certify the conversion's accounting meaning.
